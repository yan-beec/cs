# ICS 客服提醒：安装与使用说明

> **已停用：** 本文描述的是旧版纯 Python 提醒客户端及其安装包，打包功能已于 2026-11-06 从 `reminder/` 删除。客服电脑请改用 ICS 坐席客户端（Electron 版，源码在 `D:\project\chatwoot\services\chatwoot\desktop-client`）的安装包。

**适用人员：客服、班组长。适用电脑：Windows 10 / Windows 11，使用 Chrome 或 Edge 浏览器。适用版本：1.0.3。**

按照下面的顺序操作，可以让这台电脑接收自己的客户提醒，并从提醒直接打开客户聊天页面。

**首次设置顺序：安装提醒软件 → 在浏览器加入插件 → 登录客户工作台 → 选择本人座席 → 测试提醒。**

<a id="prepare"></a>

## 开始前，准备好这几样东西

1. 主管提供的安装文件：**ICSReminderSetup.exe**。
2. 自己日常接待客户使用的 Chrome 或 Edge 浏览器。后面所有浏览器操作都在这个浏览器中完成。
3. 自己的 **Chatwoot 客服账号和密码**，用于登录客户聊天工作台；不知道时向主管领取。
4. 电脑已连接公司网络，并能够打开下面的客户工作台地址。

<a id="install"></a>

## 第一步：安装提醒软件

1. 找到主管发给你的 **ICSReminderSetup.exe**，双击打开。
2. 如果电脑已安装旧版提醒软件，先打开旧程序，点击主窗口下方的 **“退出程序”**，再关闭接待客户使用的浏览器，然后继续安装。
3. 在安装窗口中找到 **“安装目录”**。可以保留窗口中的默认位置，也可以点击 **“选择安装目录”**，选择一个专门放本软件的空文件夹。
4. 例如，你可以把安装目录填写为 **D:\software\reminder**。这是一个示例，如果你选择了其他位置，后面使用你实际选择的位置。
5. 点击 **“安装到本机”**，等待显示 **“安装完成”**。
6. 点击 **“查看插件安装说明”**。把页面中显示的 **插件目录** 记下来或复制下来，第二步会用到。
7. 点击安装窗口中的 **“启动提醒程序”**。看到 **“ICS 客服提醒”** 窗口后，先让它保持打开，暂时不用填写登录信息。

**这一步完成的标志：** 已看到“ICS 客服提醒”窗口，并知道插件目录在哪里。

如果安装窗口已经关了，可以点击 Windows 左下角的 **“开始”**，搜索 **“ICS 客服提醒”** 并打开，再点击程序中的 **“浏览器插件安装说明”** 查看插件目录。

安装目录是软件日后运行要用的文件夹，请保留其中的文件。下载文件放在哪里，不影响你选择安装目录。

<a id="browser"></a>

## 第二步：把插件加入接待客户的浏览器

“插件”就是浏览器里的一个小工具。它负责把提醒软件和客户聊天页面连接起来。安装提醒软件后，还需要做这一步。

### 2.1 打开浏览器的插件管理页面

打开你接待客户使用的浏览器，点击窗口顶部的 **地址栏**，输入对应地址，再按键盘上的 **回车键**。

| 你使用的浏览器 | 在地址栏输入 |
| --- | --- |
| Google Chrome | **chrome://extensions** |
| Microsoft Edge | **edge://extensions** |

地址栏是浏览器顶部显示网址的位置。输入后应看到浏览器的“扩展程序”管理页面。

### 2.2 加入插件文件夹

1. 在刚打开的页面上找到 **“开发者模式”**，打开旁边的开关。这只是浏览器中开关的名称，照着打开即可。
2. Chrome 点击 **“加载已解压的扩展程序”**；Edge 点击 **“加载解压缩的扩展”**。不同版本可能略有字样差别，选择“加载已解压”或“加载解压缩”的按钮。
3. 在弹出的文件夹选择窗口中，找到第一步记下的 **插件目录**。
4. 如果你安装在 **D:\software\reminder**，这次要选的是里面的 **extension** 文件夹，也就是 **D:\software\reminder\extension**。
5. 可以把插件目录粘贴到文件夹选择窗口上方的地址栏，按回车进入，再点击 **“选择文件夹”**。
6. 完成后，在浏览器的插件管理页面找到 **“ICS Chatwoot 页面连接”**，确认它的开关已打开。

**这一步完成的标志：** 浏览器中出现“ICS Chatwoot 页面连接”，并已启用。

选择的是 **extension 文件夹**，不是安装文件。用默认目录安装的人，请使用安装说明页显示的实际目录。

以后请继续用这个浏览器接待客户。若改用另一个浏览器，或切换浏览器右上角头像中的另一个用户，也要在新位置完成本步和下一步。请使用普通浏览器窗口。

<a id="connect"></a>

## 第三步：填写客户工作台地址，并连接提醒程序

1. 插件加入后，通常会自动打开 **“连接 Chatwoot 页面”** 设置页。
2. 如果没有自动打开，点击浏览器右上角的 **扩展程序按钮**（通常像一块拼图），再点击 **“ICS Chatwoot 页面连接”**。
3. 在 **“Chatwoot 地址”** 中填写：**http://172.20.48.12:3000**。
4. 点击 **“保存地址并授权此站点”**。
5. 如果浏览器弹出允许访问这个网站的提示，点击 **“允许”**。如果没有弹出提示，查看页面是否已显示地址保存成功。
6. 找到设置页里的 **“桌面程序连接”**，确认显示 **“已连接桌面提醒程序”**。
7. 如果还没连接，确认“ICS 客服提醒”程序正在运行，再点击本页的 **“重新连接”**。
8. 回到“ICS 客服提醒”窗口，确认能看到 **“浏览器插件已连接”**。后面的连接数量至少为 **1** 即可。

**这一步完成的标志：** 插件设置页显示“已连接桌面提醒程序”，提醒程序显示“浏览器插件已连接”。

这里填写的地址末尾是 **3000**。请直接使用上面的地址，填写到数字 3000 为止。

<a id="workbench"></a>

## 第四步：登录自己的客户工作台

1. 在刚才安装插件的浏览器中，新开一个页面。
2. 在顶部地址栏输入 **http://172.20.48.12:3000**，按回车。
3. 用 **自己的 Chatwoot 客服账号和密码** 登录。
4. 看到客户会话列表或工作台后，核对当前登录的是自己。
5. 如果公司有多个工作台，选择主管指定的那个。
6. 按照日常值班流程，把自己在 Chatwoot 中的状态设为 **“在线”**。
7. 保留这个工作台页面。工作时可以切到其他页面，也可以最小化浏览器。

**这一步完成的标志：** 你能正常进入客户工作台，当前登录人是自己。

提醒程序中的座席选择，只决定这台电脑接收谁的提醒；接待客户时，还需要在 Chatwoot 工作台中登录自己并按要求设置在线状态。

<a id="seat"></a>

## 第五步：登录提醒程序，选择自己的座席

“座席”在这里就是接待客户的客服姓名。选谁，这台电脑就接收谁的提醒。

**如果打开程序后已经显示“当前值班席位”：** 说明这台电脑已有保存的设置。核对连接正常、座席是本人，就可以直接做第六步。只需要换人时，按本文“共用电脑：交接班怎么切换人员”操作。需要修改此前保存的地址或重新登录时，先点击 **“退出插件登录”**，回到登录页，再按下面填写。

1. 回到 **“ICS 客服提醒”** 窗口。
2. 按下面这张表填写。

| 窗口中的项目 | 填写内容 |
| --- | --- |
| ICS 地址 | **http://172.20.48.12:3001** |
| 提醒地址（可选） | **留空** |
| 账号 | **reminder** |
| 密码 | **asd!123** |

3. 点击 **“登录插件并读取授权席位”**。
4. 等待 **“坐席选择”** 下拉框显示客服名单。
5. 展开名单，**主动选择自己的姓名**。名单通常会先显示第一位客服，请仔细核对后再继续。
6. 如果有同名客服，名字旁的 **ID 数字** 是区分人员的编号，向主管确认自己对应哪个编号。
7. 如希望下次打开程序时沿用本机设置，可保留 **“在本机记住设备（Windows 用户加密保存）”** 的勾选。
8. 点击 **“使用所选席位并发送试验提醒”**。
9. 核对主窗口中的当前座席姓名，并等待试验提醒弹出。

名单中的 **online** 表示在线，**offline** 表示离线。请选择本人，接待状态按第四步在 Chatwoot 中设置。

**这一步完成的标志：** 当前座席是本人，窗口显示“ICS 已连接”，并收到试验提醒。

如果名单里没有自己，联系主管处理。不要选择其他客服的姓名来代替。

<a id="test"></a>

## 第六步：测试能否打开工作台

1. 收到 **“试验提醒”** 后，点击弹窗中的 **“打开 Chatwoot 工作台”**。
2. 确认浏览器切回刚才的客户工作台。浏览器最小化时，也应能重新显示。
3. 这时提醒窗口仍然显示，属于正常情况。点击 **“确认收到”**，结束这条试验提醒。
4. 如果有多条试验提醒，依次选中并点击 **“确认收到”**；全部确认后，提醒窗口自动收起。
5. 以后需要重新检查时，打开提醒程序主窗口，点击 **“测试提醒”**，再重复上述操作。

**试验提醒只检查软件和工作台能否连接。** 它没有真实客户，也不会显示真实收件箱名称。

请主管安排专门的测试客户，从客户入口发送 **“转人工”**，并确认会话分配给你的座席，再检查真实提醒：

1. 能看到会话编号、客户姓名、收件箱名称，例如 **“会话 56 · 客户甲 · 官网咨询”**。收件箱名称用来辨认客户来自哪个渠道。
2. 点击 **“打开 Chatwoot 工作台”** 后，能进入这位测试客户的聊天页面。
3. 点击 **“确认收到”** 后，这条提醒结束。

### 安装完成时，逐项检查

- [ ] 提醒程序显示“ICS 已连接”。
- [ ] 提醒程序显示“浏览器插件已连接”，连接数量至少为 1。
- [ ] 提醒程序当前座席姓名是本人。
- [ ] Chatwoot 工作台登录的是本人。
- [ ] 试验提醒能打开工作台，点击“确认收到”后能结束提醒。
- [ ] 在主管协助下，真实测试提醒能打开对应客户聊天页面。

以上项目都完成后，就可以正常值班了。

<a id="daily"></a>

## 日常值班：每天怎么使用

### 每天开机后

1. 点击 Windows **“开始”**，搜索并打开 **“ICS 客服提醒”**。软件目前需要手动启动，请把这一步加入每天开工检查。如果出现登录页，按第五步重新登录并选择本人。
2. 用已安装插件的浏览器打开 **http://172.20.48.12:3000**，登录自己的 Chatwoot 客服账号。
3. 核对提醒程序显示的当前座席是自己，并确认 **“ICS 已连接”**、**“浏览器插件已连接”**。
4. 按日常值班流程将 Chatwoot 状态设为在线，必要时点击 **“测试提醒”** 检查一次。

### 收到真实客户提醒后

1. 在提醒窗口里选中一条消息，查看客户姓名、收件箱名称和消息摘要。
2. 点击 **“打开 Chatwoot 工作台”**，进入对应客户聊天页面并按客服流程接待。
3. 明确收到这条提醒后，点击它的 **“确认收到”**。这只结束提醒，客户会话的回复和解决仍在 Chatwoot 中操作。
4. 多条提醒分别处理、分别确认；确认最后一条后，提醒窗口自动收起。

**打开工作台后，提醒仍会保留；未确认的提醒会继续提示。** 请通过“确认收到”结束提醒。提醒弹窗右上角的关闭按钮不能代替确认。

提醒窗口可以拖动边框调整大小。关掉提醒程序的主窗口后，它会在电脑右下角的小图标区域继续运行，仍能接收提醒。

### 关闭主窗口后，怎么再找出来

1. 看 Windows 任务栏右下角、时钟附近的小图标；如果没看到，点击 **向上的小箭头**，展开隐藏图标。
2. 找到 **铃铛形状的 ICS 提醒图标**，点击右键。
3. 点击 **“打开 ICS 客服提醒”**，恢复主窗口；点击 **“查看当前提醒”**，查看待确认消息。

需要完全停止提醒时，点击主窗口中的 **“退出程序”**，或右键铃铛图标选择 **“退出程序”**。

<a id="handover"></a>

## 共用电脑：交接班怎么切换人员

1. 按公司交接流程处理好上一班的客户会话和未确认提醒。
2. 在 Chatwoot 工作台退出上一位客服的账号，再登录接班人的 **Chatwoot 客服账号**。
3. 打开 **“ICS 客服提醒”** 主窗口。
4. 在 **“当前值班席位”** 下拉框中选择接班人的姓名。
5. 点击 **“切换席位”**，等待主窗口中的当前座席姓名变成接班人，并显示 **“ICS 已连接”**。
6. 确认浏览器插件仍已连接，点击 **“测试提醒”**，检查接班人能正常使用。
7. 接班人在 Chatwoot 中按值班要求设为在线。

正常交接使用 **“切换席位”** 即可。切换之后，这台电脑接收新座席的提醒。

<a id="update"></a>

## 以后收到新版安装文件，怎么更新

1. 打开旧版“ICS 客服提醒”，点击 **“退出程序”**。
2. 关闭接待客户使用的浏览器。
3. 双击主管提供的新版 **ICSReminderSetup.exe**。
4. 保留安装窗口显示的原安装目录，点击 **“安装到本机”**。
5. 安装完成后，启动提醒程序并重新打开浏览器。
6. 在浏览器的插件管理页面找到 **“ICS Chatwoot 页面连接”**。如果页面提供 **“重新加载”** 按钮或圆形箭头，点击一次。
7. 确认当前座席、工作台登录人和两个连接提示，再点击 **“测试提醒”** 检查。

如果需要更换软件安装位置，请先联系主管，按“卸载旧版、再安装到新目录”的方式处理。新目录安装完成后，还需要在浏览器移除原来的“ICS Chatwoot 页面连接”，再按第二、三步加入新目录里的插件并保存地址。

| 看不到收件箱名称 | 先核对是否是“试验提醒”；试验提醒没有真实收件箱。真实提醒稍等后仍缺名称，请联系主管。 |
| 关闭主窗口后找不到程序 | 到任务栏右下角展开隐藏图标，右键铃铛图标，选择“打开 ICS 客服提醒”。 |
| 重启电脑后没有提醒 | 从 Windows“开始”中打开“ICS 客服提醒”，再检查座席和两个连接提示。 |
| 换班后收到上一位客服的提醒 | 在提醒程序中选择接班人的姓名并点击“切换席位”，同时核对 Chatwoot 当前登录人。 |

### 联系主管时，说明这四件事

1. 出问题的是哪一步，例如“选择座席后没有弹出试验提醒”。
2. 提醒程序中显示的当前座席姓名。
3. 提醒程序是否显示 **“ICS 已连接”** 和 **“浏览器插件已连接”**。
4. 提示的完整文字，或能看清提示的截图。
