# 提醒客户端优化

提醒弹窗默认 `500×360`，可拖动窗口边框调整，最小 `400×300`。本次运行内收起和再次提醒沿用调整后的尺寸；重新启动恢复默认大小。长消息可滚动查看，底部操作按钮固定保留。

`1.0.2` 将所有提醒的按钮统一为“打开 Chatwoot 工作台”：试验提醒进入账户工作台，真实提醒进入对应客户会话。Chrome/Edge 浏览器插件按同站点、同账户检测并复用标签页，在页面内调用 Chatwoot 登录校验接口；没有工作台时，在已授权、已连接的浏览器配置文件中打开目标页面。

点击“打开 Chatwoot 工作台”只打开页面，提醒弹窗继续显示，当前提醒仍未确认。每条提醒需要单独点击“确认收到”；确认一条后仍有其他提醒时，弹窗继续显示剩余提醒，全部确认后才收起。会话标签字号调整为 12，摘要内容字号调整为 10。

此前 Windows UI Automation 检测已替换为浏览器官方 Native Messaging。登录过期、插件未连接或检测不完整时提示重试，不再通过默认浏览器新开重复页面。首次使用需运行统一安装包，并完成一次浏览器插件安装与站点授权，详见[安装说明](browser-extension-install.md)。

在项目根目录使用指定环境运行：

```powershell
& 'C:\Users\lenovo\Anaconda3\envs\cs\python.exe' -m reminder.client.main --demo
& 'C:\Users\lenovo\Anaconda3\envs\cs\python.exe' -m reminder.client.main
```

使用 exe 时先从系统托盘退出旧客户端，运行 `reminder/dist/browser-plugin/ICSReminderSetup.exe` 安装新版，再通过开始菜单启动。本次版本为 `1.0.2`；只关窗口会隐藏到托盘，不能切换到新版。更新后在浏览器扩展管理页重新加载插件。

真实浏览器验收：先在 Chrome/Edge 登录目标 Chatwoot 账户，将其标签切到后台，收到真实会话提醒后点击“打开 Chatwoot 工作台”，确认原标签变为目标会话、标签数量不增加且提醒弹窗仍显示。收到多条提醒时逐条点击“确认收到”，确认剩余提醒继续显示、最后一条确认后弹窗收起；再检查没有工作台、只有登录页、其他账户和检测异常的情况。这些步骤需在安装后的客户端中实际验证。
