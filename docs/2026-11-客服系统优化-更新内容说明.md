# 2026-11 客服系统优化更新内容说明（归档库 010 → 021）

| 项目 | 内容 |
| --- | --- |
| 版本范围 | 生产基线 `98188fc`（归档库迁移 010）→ `3faba61` 客服归档统计与排队优化 → `4a805a3` 评价五星与离线双包（均为 2026-11-13） |
| 需求依据 | [产品文档 V1.2](product/2026-11-客服系统优化-产品文档-V1.2.md)（R1–R13）及其后确认的补充需求 |
| 涉及范围 | ICS 智能客服、对话归档与质检、统计报表、管理后台、离线留档、坐席客户端（desktop-client） |
| 最终版本常量 | `FACT_VERSION=11`，`ROLLUP_VERSION=3`，离线 HTML 格式 3，筛选契约 1 |

本次优化主要解决三类问题：用户反复刷转人工挤占坐席；数据量变大后统计、导出报错或数值不合理；质检和归档查阅效率低。AI 应答、坐席分配和 webhook 处理这条主链路的行为保持不变。

## 一、转人工与坐席侧

**转人工动态排队（R1）**：按用户统计成功转人工次数，日计数按滚动 24 小时，周计数每周五 09:00 清零。超过档位的请求先排队，排队期间 AI 照常应答，排到后保留一次兑现机会。坐席繁忙或被拉黑不会消耗这次机会。开关、档位、人数和递减间隔都在“管理后台 → 系统管理 → 排队设置”里配置，修改可追溯，并发保存会提示冲突。首次上线时总开关默认关闭。排队模块出故障时按原流程转接，不会挡住转人工。每次排队决定都会记成证据同步到归档，归档据此撤销该次转人工请求，不会把排队误算成转人工或流单。

**黑名单（R6）**：拉黑入口统一放在坐席客户端工具栏。时长分 2 小时、24 小时、72 小时、永久四档。原因改为人工必填，修改时长和解除拉黑也要填原因或备注。任何坐席都能在客户端“黑名单”窗口修改或解除拉黑，多人同时改会提示“已被他人修改”。每次拉黑、修改、解除、到期都会留历史并同步到归档。被拉黑的客户 AI 照常接待，只拒绝转人工，提示话术和“坐席繁忙”一样，也不会弹满意度评价。黑名单已与 Chatwoot 网页端的静音功能完全脱钩，拒绝转人工只看 ICS 黑名单。升级前由静音产生的旧记录照常显示，到期或解除时顺带取消一次静音。

**快捷回复绑定坐席（R7）**：快捷回复按坐席账号保存在服务器上，换电脑登录也能取回同一份，同一台电脑切换坐席会自动切换内容。断网时可以用本机缓存，但不能修改。旧版本机数据在首次连上服务器时自动上传。登录时如果本机和服务器的内容不一致，会弹窗让坐席选择“执行同步”或“维持当前”，默认保留当前内容。本机编辑只存在本机，主动点“上传到服务器”才会整份覆盖服务器上的内容。F1 的使用方式不变。

**评价卡改五星**：满意度评价卡从表情样式改为五星样式，评分仍是 1–5 分。

**附件安全**：坐席客户端会拦截可执行文件类附件。归档后台、Excel 导出和离线留档只放行图片、视频和音频，其他文件只显示文件名，并提示客户改发截图。

## 二、统计报表

**性能与保护（R2）**：会话整理时预先计算每轮指标并按日汇总，报表只做汇总。客户消息数、轮次数、“第 N 次咨询”、当前质检结论、在线时长和黑名单状态也改为预先计算（迁移 020）。每条统计语句限时 8 秒，超时时提示缩小范围，不再把整个归档模块判为不可用。浏览器断开或取消后，后台查询随之结束并释放查询名额，不会占满名额让别人的查询报“繁忙”。Excel 导出超过上限时会逐项列出实际数量和上限，不生成残缺文件。

**考核归属**：考核坐席统一为 ICS 已确认分配的坐席。没有 ICS 分配记录的轮次不计入任何坐席，坐席细化概况里单列“无 ICS 分配轮次”。有其他坐席协助回复的轮次整轮不计入考核，只保留发配量。

**响应时长口径（R3）**：首响从转人工成功后，取客户最后一条消息到坐席首次回复之间的时长。客户分段发送时，以最后一段为起点。单段超过 600 秒的直接剔除，不截断成 600 秒。平均响应按响应次数加权汇总。

**咨询时长口径（R11）**：咨询状态总时长改为从转人工成功到会话解决的人工服务时长，中间超过 600 秒的空档不计。没有人工回复的流单不产生咨询时长。

**用户统计（R13）**：新增“用户统计”页，按成功转人工次数列出前 100 名用户，每一次转人工都能追溯并跳转到对应轮次。页面同时显示该用户近 24 小时和本周的计数，这两个数和排队模块用的是同一份数据。

**评分复核**：管理员可以在轮次详情里把访客评分标记为“有效 / 无效”。无效评分不计入评分数量、平均分和差评统计，但原始分数、反馈和聊天记录都保留，标错了也能改回。复核历史单独保存（迁移 021）。

**质检统计**：AI 质检和人工质检分别取各自最新的结论。合格、待质检和未保存结论的轮次都不算不合格。

**Excel 导出版式**：导出文件带口径说明，时长显示为时分秒，并增加合计行；坐席细化拆成 3 张表。报表各指标旁的“？”提示同步更新为新口径。

## 三、对话归档与质检

**阅读与界面（R4）**：聊天区收窄并居中。客服气泡改为浅绿色，内部备注改为黄色加虚线框，和 AI 消息更容易区分。归档界面整体更紧凑，选中的客户会置顶显示。

**筛选只看命中结果（R5）**：用了轮次级条件筛选时，列表、详情和导出都只包含命中的轮次，点进去直接看到命中的那段对话。轮次名称改为“用户第 N 次咨询 · 会话 X · 会话内第 N 轮”。

**黑名单筛选**：对话归档新增“曾被拉黑 / 当前拉黑中”筛选，列表上带拉黑标签。客户详情里显示完整的拉黑记录。

**质检结论按钮（R9）**：不再默认合格，必须主动点击结论。按纯 AI 接待和人工介入两种场景显示不同的按钮组，点击即保存，不用再点“保存”。纯 AI 接待的轮次，人工质检结论留空。“全部合格”按钮加大放在最左边。点错后直接点正确的按钮覆盖即可，历史版本可查（迁移 019）。

**时间筛选（R10）**：日期为一级选择，具体时刻收在二级展开项里。结束时间统一包含当天，即算到 23:59:59。另提供今天、昨天、近 7 天、近 30 天、本月、上月快捷按钮。

**跳页（R12）**：归档列表、详情、轮次目录和各报表的分页栏都支持输入页码跳转，并增加首页和末页按钮。

**默认范围**：归档查询默认查近 1 个月。没有设置任何筛选条件就查询时，会先弹窗提醒。

## 四、离线留档（R8）

对话归档新增“离线 HTML 留档”。可以按当前筛选导出、按月导出或导出全部历史。生成的页面双击即可离线打开，配色和后台一致。页面内的筛选项和判定口径也和后台一致，包括时间依据、坐席、评分、质检和黑名单等条件。页面不发起任何网络请求。

导出结果为两个文件：一个只含文字的 HTML，一个装原始附件的 ZIP，可以分别下载，也可以同时下载。生成前会预估数据量，过大时需要二次确认，超过上限直接拒绝。生成在低优先级的独立进程里进行。文件首次下载后保留 2 小时，24 小时内无人下载自动删除。删除记录时 HTML 和附件 ZIP 一起删除。

## 五、其他改进

**历史数据修正**：上线时对历史轮次批量重建一次，补正旧数据里的人工分类和统计事实。没有排队证据的历史轮次不会被猜成排队，日计数和周计数也不追补历史。

**存储清理**：webhook 幂等记录和 AI 对话记忆按批持续清理，直到清完为止，不再每天只删一批。进程崩溃后残留的未完成记录也纳入清理，避免这些表只增不减。

**转人工链路小优化**：坐席预留表和分配同步队列加了只覆盖有效记录的索引，查询不再随历史转人工量增长变慢。

**客户端打包**：CS 仓库里旧的 reminder 打包脚本已删除，坐席客户端统一以 Electron 版 desktop-client 为准。
