# R9 质检结论按钮实现计划

**目标：** 按本次需求实现不默认合格、按接待场景显示固定组合、点击即保存的轮次质检。

**架构：** 沿用右侧栏和追加式历史版本。数据库保存函数在事务内读取当前接待分类并校验，纯 AI 的人工结论使用 SQL NULL；前端仅高亮已保存的完整组合。

**约束：** 保留工作区已有修改；使用 CS 环境；新增注释使用中文；不改写已应用迁移，不自动提交或部署。

## 任务

- [x] 服务端：新增 019 迁移，允许人工结论为空，保存时锁定并校验当前分类；错误映射为 422，保留版本冲突和历史记录。修改 query/repository.py、runtime.py、routes.py。
- [x] 页面：修改 ics_agent/app/admin.html，替换下拉框和保存按钮，增加场景、结果组合、保存信息、备注脏状态和 Ctrl+Enter；保存失败保留草稿，分类变化时切换按钮组。
- [x] 查询与导出：人工筛选排除纯 AI，导出纯 AI 人工结论留空，保留历史待定与单项结果。
- [x] 验证：先补充并运行失败测试，再实现；运行质检、统计回归与页面交互测试，核查迁移和最终差异。

## 审查重点

- 打开未质检轮次不提交写请求，也不高亮合格。
- 分类由纯 AI 转人工后，旧 AI 结果保留，必须选择完整组合。
- 保存中重复点击和快捷键不重复写入；失败不冒充已保存。
- 备注编辑后再恢复原文可清除未保存提示；切换与分页不覆盖草稿。
- 纯 AI 的 SQL NULL 保持不适用；转人工后缺少人工结论应命中人工待定筛选。
