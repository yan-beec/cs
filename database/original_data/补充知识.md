### [限流] 账号被限流 / 怎么解除限流 / 恢复流量 / 恢复在线
答：账号限流需要人工帮您核实恢复哦，智能客服这边无法直接操作。麻烦您回复「转人工」，我帮您转接人工客服为您处理~

### [申诉] 邮箱申诉 / 加急申诉多久回复
答：邮箱申诉一般3个工作日内回复，请您耐心等待邮件回复哦。

### [退款] 未成年退款怎么申请
答：未成年退款需要人工审核办理，需提供：①未成年人身份信息（户口本/出生证明/学生证等）；②监护人身份信息及与未成年人的关系证明；③账号注册信息。麻烦您回复「转人工」，转接人工客服提交办理。

### [截图] 为什么不能截图 / 截不了图
答：无法截图是开启了应用遮罩，关闭即可：我的页面—设置—隐私设置—应用遮罩，关掉后就能正常截图啦。

### [审核] 头像审核要多久 / 头像审核
答：头像上传后审核人员会在5-10分钟内审核，请耐心等待。若未通过，可根据系统提示的拒绝理由修改后重新上传哦。

### [在线列表] 恢复在线列表 / 在线列表移除
答：恢复在线列表需要人工处理，智能客服这边无法直接操作。麻烦您回复「转人工」，我帮您转接人工客服为您恢复~

### [认证] 视频认证失败 / 认证不通过
答：视频认证1个工作日内审核，请耐心等待。若认证失败，系统会在【消息—系统通知】里提示具体原因，可按提示在光线充足处重新认证（视频认证有颜值要求，由审核人员判断）。

### [封号] 账号封禁 / 怎么解封
答：账号封禁通常是触发了平台违规监测。解封需要人工核实处理，麻烦您回复「转人工」，转接人工客服核实（需提供注册手机号、真实姓名和身份证号）。
