## 这份手册怎么用

这不是给研发看的需求文档，也不是让客服背系统名词。它主要解决四件事：星盈通到底是什么、主播要做完哪些步骤才能使用完整功能、每一步没完成会限制什么、用户说功能不能用时客服应该先查什么。

**先记住**  听到用户的问题后，不要急着判断是系统故障。先确认他用的是星盈通、兴聊还是言聊，再看账号、认证、审核、平台开通和功能开关。

**功能状态**  有些功能可能还在灰度、联调或规划中。页面上有没有、现在能不能用，以用户当前客户端、客服后台和正式运营通知为准。

## 一、先用一句话认识星盈通

**一句话**  星盈通就是主播的总工作台。主播在这里统一管理自己在兴聊、言聊的账号、资料、接单、用户、收益和任务。

兴聊和言聊仍然负责实际的聊天、语音、视频、充值和收益。星盈通把分散在两个平台里的事情集中到一个入口，让主播少切换平台，也让客服能在一个后台里查问题。

所以，星盈通不是第三个聊天平台，也不是把兴聊、言聊替换掉。它更像一个总控制台：前面帮主播统一操作，后面帮客服、审核、运营和风控统一管理。

## 二、星盈通、兴聊、言聊是什么关系

| **在哪里**     | **大白话理解**       | **主要做什么**                                   |
| -------------- | -------------------- | ------------------------------------------------ |
| 星盈通主播端   | 主播的总工作台       | 统一看账号、资料、用户、接单、数据、收益和任务。 |
| 兴聊           | 实际做业务的平台     | 承载兴聊用户、消息、通话、充值、审核和收益。     |
| 言聊           | 实际做业务的平台     | 承载言聊用户、消息、通话、充值、审核和收益。     |
| 星盈通客服后台 | 内部处理问题的工作台 | 查账号和状态，处理审核、封禁、举报、提现和异常。 |
| 公会/CPS后台   | 公会和渠道的工作台   | 管理公会账号、邀请主播、绑定关系和推广数据。     |

### 一个主播为什么会有三个ID

同一个主播在星盈通、兴聊、言聊分别注册后，每个平台都会给她一个自己的ID。这三个ID可以不同，但后台会把它们关联到同一个主播名下。

- 用户只报一个ID时，客服要问清楚这是哪个平台的ID。
- 手机号可以帮助查询，但不能只凭手机号就认定三个账号一定是同一个人。
- 查到账号后，还要看兴聊和言聊是否都已经关联、开通和正常。

**举个例子**  主播说“我的言聊资料没改”，客服不能只查星盈通账号。要同时确认她的言聊ID、言聊资料审核结果，以及资料有没有成功同步到言聊。

## 三、只注册星盈通但没有认证，会受到什么限制

**先说结论**  只完成注册，相当于“有了登录账号”，还不等于“已经成为可以经营的主播”。未认证账户的主要用途是登录、维护账号和继续完成认证；接单、修改子端资料、提现等完整业务能力还没有解锁。

**客服特别注意**  目前不同客户端版本可能会让未认证账户看到部分工作台入口或页面。能打开页面，不代表已经具备操作资格；判断能不能用，要看实名、女神身份、子端账号、平台资料和平台状态，不能只看页面有没有显示。

| **功能**               | **未认证账户能否使用** | **具体说明**                                                 |
| ---------------------- | ---------------------- | ------------------------------------------------------------ |
| 登录和账号安全         | 可以                   | 接收验证码、登录、设置或找回密码、查看自己的星盈通账号。     |
| 修改星盈通基础资料     | 部分可以               | 可按客户端入口修改星盈通自身的基础资料；昵称、头像可能要审核。这不等于修改了兴聊或言聊资料。 |
| 提交实名认证           | 可以                   | 这是未认证账户最重要的下一步。需本人姓名、身份证和人脸活体核验。 |
| 进入完整主播工作台     | 通常受限               | 登录后的业务场景优先看实名状态；未实名账户可能进入功能较少的页面，具体还受当前客户端配置影响。 |
| 提交女神申请           | 不可以                 | 女神申请的硬前置是实名认证通过，并且实名人脸基准图完整。     |
| 修改兴聊/言聊资料      | 不可以                 | 平台资料修改要求女神身份已通过；星盈通基础资料和子端平台资料是两套资料。 |
| 设置语音/视频/匹配接听 | 不可以                 | 接听开关要求女神身份，并且至少已经绑定一个子端平台。         |
| 在星盈通接听子端通话   | 不具备完整条件         | 还缺女神身份、子端账号、平台资料、平台开通、接单状态、在线状态和接听开关。 |
| 查看子端收益           | 通常没有有效数据       | 没有绑定兴聊或言聊主播账号时，子端余额会显示不可用、未绑定或为零。 |
| 绑定收款账户           | 不可以                 | 收款账户要求先实名，且户名必须与实名姓名一致。               |
| 签约和提现             | 不可以                 | 发起相关签约要实名；提现还需要子端账号、可提现余额、收款账户和页面要求的协议状态。 |

### 用户已经注册但没认证，客服怎么解释

**可以这样说**  您现在已经有星盈通登录账号，但还没有完成主播身份核验，所以目前主要能登录和继续认证。接听通话、修改兴聊或言聊资料、绑定收款账户和提现，都要在后续资格完成后逐步解锁。

- 先查星盈通ID和手机号，确认账号不是封禁、注销或关联异常。
- 再查实名状态：未提交、核验失败还是已经通过。实名是自动核验，不是长期人工排队审核。
- 如果实名失败，按页面原因处理，例如身份证格式、未成年、非女性、活体失败或人脸核验失败。
- 如果用户说“页面明明能点”，继续查具体业务门槛，不要直接判断系统已经给了权限。

## 四、完整功能怎么一步步解锁

**一条公式**  完整业务能力 = 已登录 + 实名通过 + 女神申请通过 + 子端账号已关联 + 对应平台资料完整并同步成功 + 平台已开通 + 当前功能开关满足条件。

| **阶段**        | **用户需要做什么**                     | **完成后解锁什么**                                 | **客服重点查什么**                     |
| --------------- | -------------------------------------- | -------------------------------------------------- | -------------------------------------- |
| 1. 注册成功     | 完成手机号登录，生成星盈通账号         | 登录、账号安全、继续认证                           | 手机号、区号、验证码、账号状态         |
| 2. 实名通过     | 本人姓名、身份证、人脸活体核验成功     | 实名身份、进入主播业务场景、继续女神申请和收款设置 | kyc状态、实名通过时间、实名人脸图      |
| 3. 女神通过     | 上传本人形象照，机审后等待人工终审     | 女神身份、平台资料编辑、接听开关操作资格           | 最新申请单、机审结果、人工审核、拒因   |
| 4. 子端账号就绪 | 系统关联或创建兴聊、言聊账号           | 有具体平台ID，后续可以完善各平台资料               | 两端绑定、建号结果、是否部分成功       |
| 5. 平台资料完整 | 分别补齐资料并完成审核、同步           | 该平台达到开通条件                                 | 完整度、待审项、同步失败项             |
| 6. 平台开始接单 | 平台已开通，并打开接单和接听开关       | 星盈通可以承接对应平台的业务                       | 平台状态、接单态、媒体开关、在线和忙线 |
| 7. 提现准备完成 | 绑定收款账户，按提示完成协议或结算签约 | 可提交符合规则的提现申请                           | 账户、协议、两端余额、可提现上限       |

**怎么使用这张表**  先找到用户当前停在哪一行，只处理这一行缺少的动作。上一行没有完成，不要跳到下一行排查。兴聊和言聊要分别看，因为两端可能一个成功、一个失败。

### 核心流程一：在星盈通接听兴聊、言聊通话

| **检查项**   | **要求**           | **大白话说明**                                               |
| ------------ | ------------------ | ------------------------------------------------------------ |
| 女神身份     | 必须通过           | 未通过时语音、视频、匹配和消息匹配开关不可操作。             |
| 子端账号     | 必须已绑定         | 要分别有兴聊或言聊平台ID；只绑定一个平台，就只能处理那个平台。 |
| 平台资料     | 必须达到开通条件   | 资料完整度100%，无待审项，无审核通过但同步失败项。           |
| 平台接单状态 | 必须为接单中       | 已开通但主播主动暂停，仍然不会由星盈通接单。                 |
| 星盈通在线   | 必须在线           | App离线时，即使接单开着，也不算星盈通正在接单。              |
| 对应媒体开关 | 必须开启           | 语音呼叫看语音接听，视频呼叫看视频接听，两者分别判断。       |
| 匹配接听     | 匹配单还要额外开启 | 匹配单同时要求匹配开关和对应的语音或视频开关。               |
| 忙线状态     | 必须空闲           | 正在另一端通话或忙线锁未释放时，新呼叫会被拒绝或回落。       |

1. 进入“接单设置”，分别查看兴聊、言聊卡片。只有显示平台已开通并处于接单中，星盈通才会接管该平台来电。
2. 进入“我的/接听设置”：接语音就开语音接听，接视频就开视频接听；接匹配单还要同时开匹配接听。
3. 保持星盈通登录在线。杀掉App、断网或连接离线时，接单开关的“开”不等于实际生效。
4. 来电时系统还会检查是否忙线。已经在兴聊、言聊或星盈通通话中，不能同时再接一通。

**容易误解的地方**  星盈通某一路接听开关关闭，表示星盈通不接管这一路；该通话可能回到兴聊或言聊按子端自己的开关处理，并不一定代表所有平台都彻底拒接。因此客服要先问清楚：用户说的是“星盈通没响”，还是“任何一个App都接不到”。

### 核心流程二：修改兴聊或言聊的子端资料

1. 先确认女神身份已通过。未通过时，只能继续认证或维护星盈通自身基础资料，不能修改兴聊、言聊平台资料。
2. 确认目标平台账号已经绑定。要改言聊资料，就必须查到言聊ID；只有兴聊ID时不能把修改发到言聊。
3. 进入“平台资料”，先选兴聊或言聊。两个平台的资料分别保存、分别审核、分别同步，不是一改就两边一起变。
4. 修改昵称、头像、个人介绍、语音签名、相册或标签。头像和相册可能进行本人识别或跨平台雷同检测；检测不通过时要先换材料。
5. 提交后按改动项生成审核记录。同一项正在审核时，不能再用新内容覆盖这条待审核记录。
6. 审核通过后，星盈通把结果同步到目标子端。只有“审核通过 + 同步成功 + 子端生效”都完成，用户才会在目标平台看到新资料。
7. 如果审核通过但资料没变，客服重点查同步状态和失败原因，不要让用户反复提交同一份资料。

| **资料状态**            | **代表什么**                     | **客服怎么处理**                               |
| ----------------------- | -------------------------------- | ---------------------------------------------- |
| 未填                    | 该项没有生效内容                 | 引导用户补充资料                               |
| 审核中                  | 内容已提交，尚未出结果           | 查提交时间；不要重复提交或承诺通过时间         |
| 未通过                  | 审核已拒绝                       | 查看拒因，指导用户修改后重提                   |
| 已通过，待同步/同步失败 | 中台审核结束，但目标平台还没生效 | 查目标平台、同步状态和失败原因，必要时升级重推 |
| 已生效                  | 目标平台已经使用新资料           | 让用户刷新或重新登录确认展示                   |

### 核心流程三：从有收益到完成提现

1. 先完成实名认证。没有实名时不能绑定收款账户，相关协议也不能正常发起。
2. 确认兴聊、言聊账号已绑定，并且对应平台能够正常返回余额。未绑定或余额获取失败的平台不会计入可提现上限。
3. 在收款账户中添加本人账户。户名必须与实名认证姓名一致；支付宝可用于两端，银行卡当前不能用于言聊提现。
4. 进入提现页查看是否需要完成《主播入驻协议》或兴聊结算签约、人脸确认。页面提示需要签约时，先完成签约再继续。
5. 输入提现金额。当前规则为最低10元，且必须是10元的倍数；金额不能超过页面显示的可提现上限。
6. 提交前查看试算结果，确认平台服务费、预计到账金额以及兴聊、言聊各自承担的金额。
7. 提交后系统优先使用兴聊可提现余额，不足部分再从言聊补。一次操作可能形成两端各自的处理结果。
8. 兴聊提交失败时，整笔会停止，不再提交言聊；兴聊成功但言聊失败时，会显示部分成功。此时不能让用户按原金额直接重复提交，要先核对两端结果。
9. 提现申请提交成功不等于已经到账。后续仍由对应平台审核和打款，客服要分别看兴聊、言聊的处理中、已到账或已退回状态。

## 五、其他功能速览

### 1. 用户、消息和打招呼

**说白了：**主播可以找用户、看用户主页、聊天，也可以用审核通过的打招呼模板主动联系用户。

**客服先看：**账号是否正常、对应平台是否开通、模板是否审核通过、双方是否拉黑、用户账号是否异常、模板是否同步成功。

### 2. 动态发布

**说白了：**主播发的文字和图片要先审核，再发到兴聊或言聊。发布后如果又发现问题，也可能被复审隐藏。

**客服先看：**动态ID、提交时间、发到哪个平台、审核结果、同步结果，以及发布后有没有被复审隐藏。

### 3. 数据、榜单和任务

**说白了：**主播可以看消息、通话、收益等经营数据，也可能参加榜单和每周任务。任务一般按固定周期统计，不是完成动作后马上更新。

**客服先看：**统计周期、数据更新时间、任务什么时候领取、完成条件、关窗时间、来源平台，以及奖励分平台发放状态。

### 4. 邀请、公会和活动

**说白了：**主播可以邀请其他人，也可能通过公会链接建立归属关系。能不能绑定，要看注册时间、历史关系、实名、性别和公会状态。

**客服先看：**注册时间、用户性别、以前有没有个人或公会关系、实名是否一致、公会主体是否有效、账号是否正常。

### 5. 通知、封禁和账号安全

**说白了：**通知中心会告诉主播审核、收益、违规和任务结果。账号安全包括换手机号、账号体检、设备风险、封禁和注销。

**客服先看：**封禁或经营限制记录、原因、期限、影响哪些平台、解封条件、身份核验结果，以及是否还有未完成的提现或业务单。

| “注册了/实名了，为什么还不能用”     | 能力解锁阶段还没走完                 | 对照第四章七个阶段，找到第一项未完成状态         |

| “我能登录但什么都做不了”            | 账号可能被封禁或经营受限             | 封禁记录、限制原因、期限、影响平台               |
| “帮我换手机号/注销”                 | 需要身份核验并检查未结事项           | 原手机号、实名、关联账号、余额、提现和未完成业务 |

## 七、容易混淆的后台用词

| **页面或后台会看到的词** | **大白话解释**                                     |

## 八、客服处理问题的固定顺序

1. 问清楚用户是谁：手机号和三个平台ID能提供多少就记录多少。
2. 问清楚问题发生在哪里：星盈通、兴聊、言聊还是公会后台。
3. 问清楚什么时候发生、用户刚才做了什么。
4. 先查账号、认证、平台开通、资料和功能开关。
5. 再查对应业务单：审核单、动态单、提现单、任务单或邀请关系。
6. 分别看兴聊、言聊结果，不只看星盈通总状态。
7. 能在客服权限内处理的按流程处理；不能处理的，带齐信息升级。
8. 实名、封禁、余额、提现和关系修改必须记录操作人、原因和前后状态。

## 九、升级与处理边界

### 什么情况需要升级

- 账号关系明显不对，例如同一主播关联到错误的兴聊或言聊账号。
- 审核已经通过，但某个平台长时间没有更新，而且刷新、重登无效。
- 总状态正常，但兴聊或言聊有一边一直失败。
- 提现、任务奖励出现未知状态、部分成功或长期处理中。
- 页面报错、空白、状态长期不更新，并且能够稳定复现。
- 涉及实名冲突、封禁、资产、邀请关系或公会归属，超出客服权限。

### 升级时要带哪些信息

| **信息**   | **怎么写**                                     |
| ---------- | ---------------------------------------------- |
| 账号       | 星盈通ID、兴聊ID、言聊ID、脱敏手机号           |
| 发生位置   | 星盈通 / 兴聊 / 言聊 / 客服后台 / 公会后台     |
| 发生时间   | 第一次发生时间、最近一次发生时间               |
| 用户操作   | 从哪个入口进入、点了什么、看到什么提示         |
| 业务编号   | 审核单号、动态ID、提现单号、任务ID或邀请关系ID |
| 分平台结果 | 兴聊结果、言聊结果、星盈通总状态               |
| 辅助材料   | 完整截图、录屏、错误提示、客户端版本和设备信息 |
| 已做处理   | 客服已经查了什么、指导了什么、结果怎样         |
| 希望协助   | 查原因、重试同步、确认规则或进行补偿处理       |

**隐私要求**  手机号、身份证、收款账户和聊天内容等敏感信息要脱敏，只提供排查必需内容，不在普通群聊中传播。

### 升级描述示例

**问题：**主播资料审核通过后，言聊端一直没有更新。
**账号：**星盈通ID XXXXXX；言聊ID XXXXXX；手机号已脱敏。
**时间：**2026-08-26 14:20提交，15:05审核通过，17:30仍未展示。
**现状：**星盈通显示审核通过；兴聊同步成功；言聊显示同步失败。
**已处理：**已让用户刷新并重新登录，问题仍然存在。
**需要协助：**请查看言聊同步失败原因，并确认是否需要重新推送。

### 客服不能直接承诺什么

- 不能承诺审核一定通过，或承诺具体通过时间。
- 不能直接修改实名、邀请关系或公会归属。
- 不能承诺马上解封、恢复接单或删除违规记录。
- 不能承诺补发收益、修改余额或确定具体到账时间。
- 没有分别核对兴聊、言聊状态前，不能直接说是哪一个平台故障。

**最后一句**  客服不需要记住所有系统实现，只要能问对问题、查对状态、把完整信息交给正确的人，就能把大多数问题处理清楚。
