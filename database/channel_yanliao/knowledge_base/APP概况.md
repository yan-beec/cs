# App 平台概况

**用途：** 帮助新人客服快速理解平台是什么、主要功能如何运转、接待时应把握哪些边界。

## 一、平台是什么

**本平台是一个以付费虚拟互动为核心、同时具备社交发现能力的平台。** 用户可以通过签到、任务、活动或自主充值获得平台内资费，使用资费与主播进行文字、语音、视频等线上互动；也可以通过动态、关注、好友、匹配和排行榜等功能发现合适的互动对象。

这里的“主播”是平台对认证互动服务提供者的业务称呼，主要提供一对一文字、语音或视频陪伴互动，不等同于传统公开直播间主播。

### 1.1 基本业务链路

| **第一步**       | **第二步**         | **第三步**           | **第四步**            |
| ------------- | --------------- | ----------------- | ------------------ |
| 用户通过活动或充值获得资费 | 通过动态、关注、匹配等找到主播 | 使用资费进行文字、语音、视频或送礼 | 主播获得收益，并按个人或公会方式结算 |

平台通过实名认证、视频认证、内容审核、风控、举报和申诉机制开展身份核验、风险识别、违规处置和申诉复核。

### 1.2 主要角色

| **角色**     | **概念说明**                             |
| ---------- | ------------------------------------ |
| **普通用户**   | 主要是互动消费方，可浏览资料、参与社交功能并使用资费聊天或送礼。     |
| **主播**     | 完成实名认证和视频认证后，可按平台规则提供付费互动并获得收益。      |
| **公会/邀请人** | 可能承担主播招募、管理和结算；公会关系与普通关注、好友或邀请码关系不同。 |

### 1.3 平台边界

- 平台提供线上互动和社交发现机会，不保证交友结果或线下关系。
- 平台不保证主播获得固定流量、排名、通话量或收入。
- 是否充值由用户自主决定
- 用户和主播不得通过平台进行色情低俗互动、诈骗、广告导流或私下交易。

## 二、平台有哪些主要功能

### 2.1 功能版图

| **功能类别** | **主要内容**                                       |
| -------- | ---------------------------------------------- |
| **互动功能** | 文字聊天、语音聊天、视频聊天、礼物和部分房间玩法。                      |
| **社交功能** | 动态、评论、关注、互相关注、好友/交友列表、匹配、排行榜、附近或访客等。具体入口随版本变化。 |
| **主播功能** | 实名与视频认证、资料展示、互动资费、接听设置、收益明细、等级和提现。             |
| **安全功能** | 内容审核、举报、功能限制、封禁和申诉。                            |

### 2.2 资费、会员和收益不是一回事

| **名称**                   | **主要用途**                            |
| ------------------------ | ----------------------------------- |
| **资费余额、金币等**             | 用户消费侧资产，用于文字、语音、视频或部分礼物。不同版本名称可能不同。 |
| **视频卡、通话卡等**（**优先于金币使用**） | 抵扣指定互动时长或次数，受卡种、来源和有效期限制。           |
| **会员/VIP/爵位**            | 独立会员权益，不代表所有文字、语音和视频免费。             |
| **积分**                   | 主播侧收益记录，是否可提现及换算方式以当前收益页为准。         |

**基本计费概念：**

- 文字聊天通常按条计费，语音和视频通常按分钟计费。
- 可配置项目由主播在平台允许范围内设置，其他项目可能采用系统价格或等级区间。
- 所有价格、最小计费单位和卡券抵扣均以互动前页面及账单为准。
- 双方互相关注后是否有文字优惠，要看好友状态和当前发送页；不能把互关理解为所有互动免费。

### 2.3 主播如何开通

本手册按当前业务口径，将**实名认证 + 视频认证**作为完整主播的主干准入标准：

1. 注册并完善本人资料；
2. 完成实名认证；
3. 使用本人真实、清晰、合规的资料完成视频认证；
4. 审核通过后开通相应主播能力；
5. 按页面配置互动和收益相关功能。

部分版本还可能展示语音认证、女神认证或等级认证，它们属于具体能力或进阶权益，应按当前认证页逐项解释。客服只能说明状态、拒绝原因和重新提交方式，不能代审或保证通过。

### 2.4 社交与内容安全

动态、关注、好友和匹配用于建立互动连接，但普通聊天不支持发送或诱导添加个人联系方式。出现色情低俗、诈骗、骚扰、站外导流、恶意挂断等问题时，应停止互动、保留必要证据，并通过当前版本的举报入口提交。具体入口以用户当前页面为准，处理结果以系统通知为准。

## 三、客服必须理解的几个关键点

### 3.1 推荐、流量和限流

推荐和匹配由系统自动判断，系统可能综合参考资料、活跃、回复、接通和互动质量等信号；客服不能人工指定推流、解释固定算法权重或保证排名。

**流量少不等于限流。** 限流通常会有明确页面或系统提示。客服只有在核实确有提示且权限允许时，才能恢复限制状态；“限制已解除”不等于平台立即增加推荐、来电或收益。

### 3.2 主播收益与提现

主播可通过合规的文字、语音、视频和礼物互动获得收益。消费价格、主播分成、收益数值和最终提现金额是不同概念，不能混为一谈。

**提现前必须先区分：**

| **类型**     | **结算方式**                     |
| ---------- | ---------------------------- |
| **个人提现**   | 平台按当前财务批次向提现页绑定并通过核验的收款账户结算。 |
| **公会打包提现** | 平台先与公会结算，再由公会或邀请人向主播结算。      |

提现不是实时到账。具体门槛、批次、手续费、税费和节假日安排以当前提现页和财务公告为准。

9. **不作越权承诺**： 不保证推流、过审、解封、退款、处罚、到账或固定收益。
10. **高风险问题及时升级**： 未成年人充值、盗刷、诈骗、身份冒用、永久封禁、公会结算争议和重大安全事件必须走专项流程。

### 3.4 容易答错的概念

| **用户问题**          | **正确理解**                               |
| ----------------- | -------------------------------------- |
| **“不充值能不能用？”**    | 充值是自主选择；可先使用已有资费、卡券或当前活动权益，也可以通过活动获取资费 |
| **“有会员为什么还扣费？”**  | 会员与聊天资费是两类权益，具体看会员中心。                  |
| **“没人联系我是不是限流？”** | 不一定；先看是否有明确限流提示。                       |
| **“互关以后都免费吗？”**   | 先看双方好友状态和当前价格提示，语音、视频不能默认免费。           |
| **“提现为什么没到账？”**   | 先区分个人提现和公会打包提现，再查批次与状态。                |
| **“充值能不能退款？”**    | 先区分普通反悔、未到账、重复扣款、未成年人或未授权支付，再按对应流程处理。  |

**动态规则提醒：** 资费、活动奖励、卡券有效期、审核时长、提现批次、版本入口和处罚期限都会调整。新人应掌握平台概念和判断方法，具体数字永远以用户当前页面、客服后台、最新公告及正式制度为准。

**一句话总结：** 本平台通过“社交发现 + 付费互动”连接普通用户与认证主播，再由认证、计费、推荐、结算和内容治理体系保障整个服务过程。
