# 本软件 · 产品介绍及使用指南

---

## 一、产品概览

本软件件件是一款以**真人语音 / 视频社交**为核心的 App，采用「主播 — 用户」互动模式：

- 用户通过**语音通话、视频通话、文字聊天**与主播互动；
- 通话**按时长计费**，资费由**主播自行设置**；
- 主播可通过通话、直播推广、邀请好友等方式获得**收益**，收益以星光值等形式结算并支持**提现**；
- 平台设有**真人认证、内容审核、防诈骗**等安全机制。

**关联说明**：本软件件件与公司旗下其他平台数据独立；属于合作平台。但是账户违规被封会无法使用所有平台。

| 分成        | 收益计算方式：由系统计算                           |

## 三、账号与注册

- 使用**手机号**即可注册登录；
- 没有账号：用手机号注册一个即可；
- 账号的实名认证是核验身份的主要依据，咨询时可能需要提供。

## 四、认证与内容审核

- **视频认证**：由审核人员判断，对颜值有一定要求，需要化妆和调整滤镜后开始认证；
- 未通过时会给出**拒绝理由**，可以在系统通知查看。按理由修改后**重新上传**即可；
- 视频认证未通过**不影响平台基本使用**；
- **头像、动态**等内容需经审核，审核由平台排队处理；
- **视频通话中禁止截屏、录屏**；
- 平台**不支持发送包含第三方联系方式的信息**，也**不建议与网友线下见面**（防诈骗）。

## 五、充值、资费与消费

**充值渠道**

- App 内充值；
- 微信右上角「+」→ 添加朋友 → 服务号 → 搜索【言聊】服务号内操作充值；
- **苹果手机**（含没有 Apple ID 的情况）同样可通过微信服务号完成充值。

**计费规则**

| 项目   | 规则                        |
| ---- | ------------------------- |
| 通话资费 | 由主播自行设置，在对方主页右下角点击「拨打」可查看 |

**退款政策**：虚拟商品性质与实体商品不同，**已充值的虚拟产品不支持退款**，可通过聊天 / 送礼的形式消费。

## 六、会员与卡券

- **会员 28 元 / 月** → 赠送 **3 张通话卡**，每张 **1 分钟**，语音、视频通用；
- 会员权益均会在 App 页面展示，可直接查看；
- **通话卡 / 视频卡**：在拨打视频通话时**自动抵扣**；
- 会员权益**暂不支持转换或退换**。

## 七、收益与提现

**收益来源**

- 主播和用户通话，主动拨打和接受通话，均由用户支出资费给主播**均可产生收益**；
- 付费方为**发起通话的用户**；
- 每天前三分钟的匹配类型通话主播没有收益，主动拨打和反打通话没有影响
- **直播推广**：主播打开「视频直播推广视频」按钮后，可接到推广视频，画面会被直播到**合作的其他平台**并产生收益——是否开启由主播自行决定。

**收益计算**

- `资费 × 分成 = 每分钟收益`；
- 使用一张视频卡，系统补贴 **50积分（= 0.5 元）**；
- 对方使用**活动币或赠送币**时，收益比例会降低；
- 最终**以系统到账为准**。

**提现到账时间**（节假日另行通知）

| 提现日          | 到账时间        |
| ------------ | ----------- |
| 周一           | 周三 24:00 前  |
| 周二           | 周四 24:00 前  |
| 周三           | 周五 24:00 前  |
| 周四           | 下周一 24:00 前 |
| 周五 / 周六 / 周日 | 下周二 24:00 前 |

> 由**公会统一结算**的主播，提现打款由**邀请人**负责处理，请自行联系邀请人查询打款进度。
