# 星盈通 · 智能客服回复参考文档

---

## 一、星盈通是什么

### 1.1 一句话理解

**星盈通是主播的统一工作台**，也是内部处理主播问题的统一管理中台。

主播可以在星盈通集中管理自己在**兴聊、言聊**等业务平台中的主播账号，完成认证、资料维护、用户沟通、接单设置、动态发布、经营数据查看、收益提现、任务及邀请等操作。

### 1.2 与兴聊、言聊的关系

- 星盈通**不是**兴聊或言聊的替代产品。
- **兴聊、言聊**负责承载具体用户、消息、通话、充值和收益业务。
- **星盈通**负责提供统一账号体系、统一操作入口、统一数据展示以及跨平台管理能力。
- 星盈通不是第三个聊天平台。它更像一个总控制台：前面帮主播统一操作，后面帮内部统一管理。

### 1.3 星盈通主要解决的问题

1. 多个平台账号分散，主播需要重复维护资料和经营设置。
2. 各平台认证、审核、接单和收益状态不一致，问题定位困难。
3. 收益数据分散，主播难以统一查看。
4. 消息、通话、动态和用户关系分布在不同业务平台，缺少统一入口。
5. 封禁、资料审核、提现和跨平台同步需要统一状态和补偿机制。

## 二、产品组成与三端账号关系

### 2.1 产品端一览

| 在哪里      | 大白话理解     | 主要做什么                    |
| -------- | --------- | ------------------------ |
| 星盈通主播端   | 主播的总工作台   | 统一看账号、资料、用户、接单、数据、收益和任务。 |
| 兴聊       | 实际做业务的平台  | 承载兴聊用户、消息、通话、充值、审核和收益。   |
| 言聊       | 实际做业务的平台  | 承载言聊用户、消息、通话、充值、审核和收益。   |
| 公会/CPS后台 | 公会和渠道的工作台 | 管理公会账号、邀请主播、绑定关系和推广数据。   |

### 2.2 一个主播为什么会有三个 ID

- 同一名主播可能同时拥有一个**星盈通统一账号**、一个**兴聊主播账号**和一个**言聊主播账号**。
- 系统通过**账号映射关系**识别同一主播，但各端 ID、开通状态和业务状态**仍然独立**。
- 任一平台分别注册后，每个平台都会给一个自己的 ID。这三个 ID 可以不同，但后台会把它们关联到同一个主播名下。
- 手机号只能作为**辅助查询条件**，不能代替账号关系确认，也不能只凭手机号就认定三个账号一定是同一个人。
- 用户端部分页面不展示来源平台，但后台会保留来源信息用于路由和排查。
- 跨平台同步可能出现**一端成功、一端失败**，不能只看总状态。

### 2.3 智能客服需特别注意的三点

1. 用户只报一个 ID 时，要问清楚**这是哪个平台的 ID**。
2. **账号生成不等于平台已经开通**。主播还需要满足认证、资料和平台资格要求，才能在对应平台展示、接单和结算收益。
3. 同步失败一般不直接判断为账号丢失，需要区分账号未关联、平台未开通、资料同步失败和缓存未刷新。

## 三、名词与货币口径

| 名词      | 对用户的解释                                  |
| ------- | --------------------------------------- |
| 星盈通ID   | 用户在星盈通统一账户体系中的唯一标识。                     |
| 平台ID    | 用户在兴聊或言聊中的业务账号标识。                       |
| 账号关联    | 把同一个主播的星盈通、兴聊、言聊账号对应起来。                 |
| 平台开通    | 主播在对应平台取得展示、接单和收益资格的状态。                 |
| 同步      | 星盈通把资料或操作结果发给兴聊、言聊。                     |
| 同步失败    | 星盈通这边处理完了，但目标平台没有成功更新或生效。               |
| 部分成功    | 跨平台操作中至少一个平台成功、至少一个平台未成功（例如兴聊成功、言聊没成功）。 |
| 审核单     | 保存审核对象、提交内容、结果、原因和处理时间的记录。              |
| 总单 / 子单 | 一笔提现的总记录，以及按兴聊、言聊拆开的处理记录。               |
| 经营限制    | 账号还能登录，但接单、发消息等部分功能不能用。                 |
| 星币      | 星盈通统一展示的收益单位；当前产品口径为 **100 星币 = 1 元**。  |
| 星光值     | 兴聊主播侧收益单位；当前换算口径为 **15 星光值 = 1 元**。     |
| 积分      | 言聊主播侧收益单位；当前口径下 **100 积分 = 100 星币**。    |
| 金币      | 兴聊、言聊男用户侧充值货币，**不等同于**主播可提现的星币。         |

> **口径提醒**：换算、任务奖励、排行榜和活动规则可能调整。涉及具体金额和权益时，以用户页面当期规则、正式公告和后台实际数据为准。

## 四、功能解锁条件

### 4.1 核心公式

> **完整业务能力 = 已登录 + 实名通过 + 女神申请通过 + 子端账号已关联 + 对应平台资料完整并同步成功 + 平台已开通 + 当前功能开关满足条件。**

任一步骤未完成，都可能影响后续能力。例如认证未通过会影响接单，资料审核中会影响平台展示，平台未开通会影响该平台用户、通话和收益数据。

### 4.2 七阶段解锁路径

| 阶段        | 用户需要做什么             | 完成后解锁什么                   |
| --------- | ------------------- | ------------------------- |
| 1. 注册成功   | 完成手机号登录，生成星盈通账号     | 登录、账号安全、继续认证              |
| 2. 实名通过   | 本人姓名、身份证、人脸活体核验成功   | 实名身份、进入主播业务场景、继续女神申请和收款设置 |
| 3. 女神通过   | 上传本人形象照，机审后等待人工终审   | 女神身份、平台资料编辑、接听开关操作资格      |
| 4. 子端账号就绪 | 系统关联或创建兴聊、言聊账号      | 有具体平台 ID，后续可以完善各平台资料      |
| 5. 平台资料完整 | 分别补齐资料并完成审核、同步      | 该平台达到开通条件                 |
| 6. 平台开始接单 | 平台已开通，并打开接单和接听开关    | 星盈通可以承接对应平台的业务            |
| 7. 提现准备完成 | 绑定收款账户，按提示完成协议或结算签约 | 可提交符合规则的提现申请              |

> **使用提示**：用户说"为什么还不能用"时，先找到他当前停在哪一个阶段，再针对这一阶段缺少的动作回复。**上一阶段没完成，不要跳到下一阶段解释。**兴聊和言聊要分别看，因为两端可能一个成功、一个失败。

### 4.3 只注册星盈通但未认证，会受到什么限制

**先给用户结论**：只完成注册，相当于"有了登录账号"，还不等于"已经成为可以经营的主播"。未认证账户的主要用途是登录、维护账号和继续完成认证；接单、修改子端资料、提现等完整业务能力还没有解锁。

| 功能           | 未认证账户能否使用 | 具体说明                                            |
| ------------ | --------- | ----------------------------------------------- |
| 登录和账号安全      | 可以        | 接收验证码、登录、设置或找回密码、查看自己的星盈通账号。                    |
| 修改星盈通基础资料    | 部分可以      | 可按客户端入口修改星盈通自身的基础资料；昵称、头像可能要审核。这不等于修改了兴聊或言聊资料。  |
| 提交实名认证       | 可以        | 这是未认证账户最重要的下一步。需本人姓名、身份证和人脸活体核验。                |
| 进入完整主播工作台    | 通常受限      | 登录后的业务场景优先看实名状态；未实名账户可能进入功能较少的页面，具体还受当前客户端配置影响。 |
| 提交女神申请       | 不可以       | 女神申请的硬前置是实名认证通过，并且实名人脸基准图完整。                    |
| 修改兴聊/言聊资料    | 不可以       | 平台资料修改要求女神身份已通过；星盈通基础资料和子端平台资料是两套资料。            |
| 设置语音/视频/匹配接听 | 不可以       | 接听开关要求女神身份，并且至少已经绑定一个子端平台。                      |
| 在星盈通接听子端通话   | 不具备完整条件   | 还缺女神身份、子端账号、平台资料、平台开通、接单状态、在线状态和接听开关。           |
| 查看子端收益       | 通常没有有效数据  | 没有绑定兴聊或言聊主播账号时，子端余额会显示不可用、未绑定或为零。               |
| 绑定收款账户       | 不可以       | 收款账户要求先实名，且户名必须与实名姓名一致。                         |
| 签约和提现        | 不可以       | 发起相关签约要实名；提现还需要子端账号、可提现余额、收款账户和页面要求的协议状态。       |

**可直接使用的解释口径**

> 您现在已经有星盈通登录账号，但还没有完成主播身份核验，所以目前主要能登录和继续认证。接听通话、修改兴聊或言聊资料、绑定收款账户和提现，都要在后续资格完成后逐步解锁。

**回复时需向用户说明的要点**

1. 先确认星盈通 ID 和手机号，排除账号封禁、注销或关联异常。
2. 再确认实名状态：未提交、核验失败还是已经通过。**实名是自动核验，不是长期人工排队审核。**
3. 实名失败时按页面原因说明，例如身份证格式、未成年、非女性、活体失败或人脸核验失败。
4. 用户说"页面明明能点"时，说明**能打开页面不代表已经具备操作资格**，判断能不能用要看实名、女神身份、子端账号、平台资料和平台状态。

## 五、核心功能的使用条件

### 5.1 登录、注册与账号关联

- 主播使用手机号登录或注册星盈通。系统会识别其在兴聊、言聊的账号情况，并根据实际状态完成账号关联、资料同步或缺失账号补建。
- **账号生成不等于平台已经开通。**
- 同步失败一般不应直接判断为账号丢失，需要区分账号未关联、平台未开通、资料同步失败和缓存未刷新。

### 5.2 实名认证与女神申请

- 主播需要根据页面要求完成实名认证、主播认证或女神申请。认证结果会影响接单、资费、打招呼和平台经营资格。
- 常见状态包括：**未提交、审核中、审核通过、审核驳回**。驳回后通常可以查看原因、修改资料并重新提交。
- 女神申请的硬前置是**实名认证通过**，并且**实名人脸基准图完整**。
- 不可仅凭用户口述确认认证结果，应以页面显示的状态、驳回原因和最近提交时间为准。

### 5.3 平台资料管理（核心流程二）

**前置条件**

1. 确认**女神身份已通过**。未通过时，只能继续认证或维护星盈通自身基础资料，**不能修改兴聊、言聊平台资料**。
2. 确认**目标平台账号已经绑定**。要改言聊资料，就必须有言聊 ID；只有兴聊 ID 时不能把修改发到言聊。

**操作与生效路径**

1. 进入"平台资料"，先选兴聊或言聊。**两个平台的资料分别保存、分别审核、分别同步，不是一改就两边一起变。**
2. 修改昵称、头像、个人介绍、语音签名、相册或标签。头像和相册可能进行本人识别或跨平台雷同检测；检测不通过时需要先换材料。
3. 提交后按改动项生成审核记录。**同一项正在审核时，不能再用新内容覆盖这条待审核记录。**
4. 审核通过后，星盈通把结果同步到目标子端。只有"**审核通过 + 同步成功 + 子端生效**"都完成，用户才会在目标平台看到新资料。

**资料各状态的含义**

| 资料状态         | 代表什么             | 应如何向用户说明                                            |
| ------------ | ---------------- | --------------------------------------------------- |
| 未填           | 该项没有生效内容         | 引导用户补充资料。                                           |
| 审核中          | 内容已提交，尚未出结果      | 说明提交后将按审核进度处理，**不承诺通过时间，也不建议重复提交**。                 |
| 未通过          | 审核已拒绝            | 请用户查看拒因，修改后重新提交。                                    |
| 已通过，待同步/同步失败 | 中台审核结束，但目标平台还没生效 | 说明审核已完成、平台生效未完成，可建议刷新或重新登录确认；若长时间无效，建议联系人工客服核实同步状态。 |
| 已生效          | 目标平台已经使用新资料      | 请用户刷新或重新登录确认展示。                                     |

> 审核通过但资料没变时，重点说明问题在**同步或平台生效**环节，不要引导用户反复提交同一份资料。

### 5.4 用户发现与关系管理

- 主播可查看推荐、活跃、附近等用户列表，也可以通过用户 ID 搜索用户，并进入主页发起打招呼、消息、语音或视频。
- 系统会管理关注、拉黑、访客、历史会话和关系用户等信息。**拉黑方向不同会导致不同的拦截结果。**
- 用户端通常不展示兴聊或言聊来源标签，但后台仍保留来源平台，以保证消息和通话被正确路由。

### 5.5 消息与打招呼

- 主播可以在会话页与用户聊天，也可以使用**审核通过**的打招呼模板主动触达用户。
- 新建或修改模板后需要审核。模板审核通过后，还可能需要同步到已开通的平台。
- 无法发送时，涉及的因素包括：账号状态、模板审核状态、平台开通状态、双方拉黑关系和同步状态。

### 5.6 语音、视频与接单设置（核心流程一）

主播可以分别管理语音、视频及匹配相关开关，并在允许范围内设置资费。**接单能力通常受认证、平台开通、资料状态、账号状态、经营限制和接单开关共同影响，不能只看某一个开关。**

**在星盈通接听兴聊、言聊通话，需要同时满足以下全部条件：**

| 检查项    | 要求        | 大白话说明                             |
| ------ | --------- | --------------------------------- |
| 女神身份   | 必须通过      | 未通过时语音、视频、匹配和消息匹配开关不可操作。          |
| 子端账号   | 必须已绑定     | 要分别有兴聊或言聊平台 ID；只绑定一个平台，就只能处理那个平台。 |
| 平台资料   | 必须达到开通条件  | 资料完整度 100%，无待审项，无审核通过但同步失败项。      |
| 平台接单状态 | 必须为接单中    | 已开通但主播主动暂停，仍然不会由星盈通接单。            |
| 星盈通在线  | 必须在线      | App 离线时，即使接单开着，也不算星盈通正在接单。        |
| 对应媒体开关 | 必须开启      | 语音呼叫看语音接听，视频呼叫看视频接听，两者分别判断。       |
| 匹配接听   | 匹配单还要额外开启 | 匹配单同时要求匹配开关和对应的语音或视频开关。           |
| 忙线状态   | 必须空闲      | 正在另一端通话或忙线锁未释放时，新呼叫会被拒绝或回落。       |

**用户可自查的操作路径**

1. 进入"接单设置"，分别查看兴聊、言聊卡片。只有显示平台已开通并处于接单中，星盈通才会接管该平台来电。
2. 进入"我的 / 接听设置"：接语音就开语音接听，接视频就开视频接听；接匹配单还要同时开匹配接听。
3. 保持星盈通登录在线。杀掉 App、断网或连接离线时，接单开关的"开"不等于实际生效。
4. 来电时系统还会检查是否忙线。已经在兴聊、言聊或星盈通通话中，不能同时再接一通。

> **容易误解的地方**：星盈通某一路接听开关关闭，表示星盈通不接管这一路；该通话可能回到兴聊或言聊按子端自己的开关处理，**并不一定代表所有平台都彻底拒接**。因此要先问清楚：用户说的是"星盈通没响"，还是"任何一个 App 都接不到"。

### 5.7 动态发布

- 主播可以编辑文字、图片等动态内容，并发布到可用平台。动态提交后需要经过内容审核，通过后再同步到对应平台。
- 动态未展示可能处于：未提交、审核中、审核驳回、同步失败、发布后复审隐藏等不同阶段。
- 涉及因素：动态 ID、提交时间、目标平台、审核结果和同步结果。避免只回复"审核未通过"。

### 5.8 数据、榜单与任务

- 主播可以查看用户触达、消息、通话、收益等经营数据，也可能看到女神魅力榜、用户排行榜和每周任务。
- 榜单和任务通常按固定周期统计，可能存在数据延迟、任务领取条件、完成条件和关窗时间。
- 任务奖励是否到账，应同时看任务总状态及**各来源平台**的发放状态。页面当期规则优先于历史口径。

### 5.9 收益、提现与签约（核心流程三）

**前置准备**

1. 先完成实名认证。没有实名时不能绑定收款账户，相关协议也不能正常发起。
2. 确认兴聊、言聊账号已绑定，并且对应平台能够正常返回余额。未绑定或余额获取失败的平台不会计入可提现上限。
3. 在收款账户中添加本人账户。**户名必须与实名认证姓名一致；支付宝可用于两端，银行卡当前不能用于言聊提现。**
4. 进入提现页查看是否需要完成《主播入驻协议》或兴聊结算签约、人脸确认。页面提示需要签约时，先完成签约再继续。

**提现规则与流程**

1. 输入提现金额。**当前规则为最低 100 元，且必须是 100 元的倍数**；金额不能超过页面显示的可提现上限。
2. **提现申请提交成功不等于已经到账。**后续仍由对应平台审核和打款，兴聊、言聊各自有处理中、已到账或已退回状态。一般在三个工作日内完成。

**金额概念必须区分清楚**

- **总余额、可提现余额、申请金额和实际到账金额不是同一概念。**
- 冻结、未结算、提现中或平台限制都会造成差异。
- 提现可能按收益来源拆分处理，因此会出现全部成功、部分成功、失败或处理中等状态。

### 5.10 邀请、公会与活动

- 主播可以通过邀请功能邀请其他主播或用户，并按当期规则获得奖励。公会邀请还涉及公会归属、绑定关系和收益结算。
- 邀请或公会绑定可能受：注册时间、账号性别、历史邀请关系、公会关系和实名信息是否一致影响。
- 邀请关系、资产奖励和公会归属属于敏感数据，**不能口头承诺修改**。

### 5.11 通知、会员与账号安全

- 通知中心用于接收收益、审核、违规、任务及系统消息；会员能力以客户端当前展示的档位和权益为准。
- 账号安全能力包括更换手机号、账号体检、实名认证、设备风险识别、封号记录和账号注销等。
- 更换手机号、实名豁免、解封、注销和设备风险处理**均需要核验身份并保留后台操作记录**，属于需要人工客服跟进的事项。

## 六、常见状态的含义

| 状态类型   | 常见表现                 | 对用户的解释                |
| ------ | -------------------- | --------------------- |
| 账号状态   | 正常、异常、封禁、注销等         | 决定能否登录及使用经营功能。        |
| 平台开通状态 | 未开通、开通中、已开通、开通失败     | 决定是否展示该平台用户、动态、接单和收益。 |
| 认证状态   | 未提交、审核中、通过、驳回        | 决定主播资格及部分经营能力。        |
| 资料状态   | 草稿、待审、通过、驳回、同步失败     | 决定资料是否能在目标平台展示。       |
| 接单状态   | 开启、关闭、受限             | 受认证、平台资格、经营限制和开关共同影响。 |
| 动态状态   | 待审、通过、驳回、同步失败、复审隐藏   | 决定动态是否在目标平台可见。        |
| 提现状态   | 处理中、成功、部分成功、失败等      | 需要分别看兴聊、言聊两端结果。       |
| 任务状态   | 待领取、进行中、复核中、待结算、已发放等 | 决定是否继续累计、是否进入发奖。      |

**资料审核与生效链路**：填写并提交资料 → 系统生成审核单，进入待审核状态 → 审核通过或驳回，记录审核结果和原因 → 审核通过后，系统向目标平台同步资料 → 目标平台接收成功后，资料才进入实际生效阶段。

> 因此"审核通过"只能证明审核结果，**不一定证明目标平台已经同步生效**。

## 七、用户常见问法 → 回复参考

> 说明：以下每条"回复参考"均为原文检查项/说明口径的用户向改写，不含原文之外的新规则。

### Q1 我登录不了 / 收不到验证码

**回复参考**：请依次检查手机号与区号是否填写正确、是否短时间内频繁获取验证码、验证码是否已超过有效期、账号状态是否正常，以及客户端是否为最新版本。

**需向用户确认**：手机号、区号、获取验证码的时间与次数、账号是否可正常登录其他入口、客户端版本。

### Q2 我注册了 / 实名了，为什么还不能用

**回复参考**：星盈通需要女神认证通过后可以使用，您可以在认证中心认证后使用相关功能。

### Q3 找不到我的另一个账号

**回复参考**：星盈通、兴聊、言聊各有独立 ID，系统通过账号关联识别为同一主播，但三端 ID 和状态相互独立，需要确认账号是否已关联、手机号是否一致、账号是否已注销、实名信息是否一致。

**需向用户确认**：三个平台的 ID（能提供多少记多少）、注册手机号、账号是否注销。

### Q4 有账号但不能接单

**回复参考**：接单能力受多个条件共同影响，不只是某一个开关。请依次确认：认证状态、对应平台是否已开通、平台资料是否完整并同步成功、是否有经营限制、接单开关是否打开、资费是否已设置。

### Q5 认证一直显示审核中

**回复参考**：认证结果以页面最新一条审核记录为准。请确认提交时间、审核单当前状态、所提交素材是否完整，以及是否存在重复提交产生多条待审记录的情况。审核中不建议重复提交。

### Q6 为什么提交不了女神申请

**回复参考**：女神申请的硬前置是实名认证已通过，并且实名人脸基准图完整。请先确认实名认证状态。

### Q7 资料审核通过了，为什么还没展示

**回复参考**：审核通过、同步成功、平台生效是三个不同阶段。请确认目标是兴聊还是言聊、审核通过时间，以及该平台的同步状态。若显示同步失败，或长时间刷新、重新登录后仍无变化，建议联系人工客服核实同步状态。

> 注意：一个平台已经生效，不代表另一个平台也同步成功。

### Q8 消息发不出去 / 打招呼发不出去

**回复参考**：请确认账号状态是否正常、对应平台是否已开通、打招呼模板是否已审核通过、双方是否存在拉黑关系、对方账号是否异常，以及模板是否已同步成功。

### Q9 平台已开通、开关也开着，但星盈通不响

**回复参考**：接听需要同时满足全部条件：女神身份通过、子端账号已绑定、平台资料达到开通条件、平台接单状态为接单中、星盈通保持在线、对应媒体开关已开启（语音呼叫看语音接听、视频呼叫看视频接听）、匹配单还需开启匹配接听、且不处于忙线状态。请逐项确认。

**需向用户确认**：是"星盈通没响"，还是"任何一个 App 都接不到"。星盈通某一路开关关闭，只表示星盈通不接管这一路，通话可能回到对应子端按其自身开关处理。

### Q10 动态不见了 / 没有展示

**回复参考**：动态从提交到可见需要经过审核，并同步到目标平台。未展示可能处于：未提交、审核中、审核驳回、同步失败、或发布后被复审隐藏。

**需向用户确认**：动态提交时间、发布到哪个平台、以及页面提示的内容。

### Q11 任务完成了却没有进度

**回复参考**：任务一般按固定周期统计，不是完成动作后马上更新。请确认任务领取时间、当前统计周期、完成条件、以及奖励分平台发放状态。

### Q12 总收益跟预期不一致

**回复参考**：星盈通展示的是跨平台聚合结果，按统一单位换算，但实际资产仍需区分来源平台。请确认收益来源平台、结算周期、换算口径，以及是否存在冻结或未结算金额。

> 口径参考：星币 100 = 1 元；星光值 15 = 1 元；积分 100 = 100 星币；金币是男用户充值货币，不等于可提现星币。

### Q13 提现失败 / 只到账了一部分

**回复参考**：提现会按收益来源拆分处理，可能出现全部成功、部分成功、失败或处理中。兴聊提交失败时整笔会停止、不再提交言聊；兴聊成功但言聊失败时会显示部分成功。一笔申请提交成功也不等于已经到账，两端会各自有处理中、已到账或已退回状态。

**需向用户确认**：提现申请时间、金额、页面显示的总单状态及两端结果。如需核对具体子单，建议联系人工客服。

### Q14 邀请码绑不上 / 公会绑定失败

**回复参考**：能否绑定要综合看注册时间、账号性别、是否已存在历史邀请或公会关系、实名信息是否一致，以及公会主体和账号状态是否正常。

### Q15 我能登录但什么都做不了

**回复参考**：账号可以登录但部分经营能力被关闭或限制，属于经营限制状态。需要确认封禁或经营限制记录、原因、期限，以及影响的是哪些平台。

### Q16 帮我换手机号 / 我要注销账号

**回复参考**：更换手机号和账号注销都需要完成身份核验，并检查是否存在未完成事项，例如关联账号、余额、提现中或未结束的业务单。此类操作需由人工客服按流程处理，智能客服无法直接执行。

### Q17 我改了兴聊/言聊资料，怎么没生效

**回复参考**：修改兴聊或言聊资料需要女神身份已通过，且目标平台账号已绑定；两个平台的资料分别保存、分别审核、分别同步。请确认资料当前状态：未填 / 审核中 / 未通过 / 已通过但待同步或同步失败 / 已生效。
