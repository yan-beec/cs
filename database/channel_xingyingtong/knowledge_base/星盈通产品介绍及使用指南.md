# 星盈通 · 产品介绍及使用指南

---

## 一、产品概述

星盈通是一款面向平台主播的 **聚合端应用**，用于把旗下两款 1V1 社交 / 视频通话应用 —— **兴聊** 与 **言聊** —— 的账号统一聚合在一起，集中管理、统一操作。主播无需在两个 App 之间来回切换，即可在一个客户端内统一处理兴聊、言聊的通话与消息。

| 项目   | 说明                                |
| ---- | --------------------------------- |
| 产品性质 | 主播专用聚合操作端                         |
| 适用人群 | 在兴聊、言聊上开展 1V1 视频 / 语音陪聊业务的主播      |
| 核心价值 | 把多个子平台的账号与业务「合二为一」：统一登录、统一操作、统一管理 |
| 承载业务 | 1V1 真人视频 / 语音陪聊、语音房（以平台实际开放为准）    |

> 星盈通本身会新建独立账号体系，以便管理已有的子端账号运行。

---

## 二、产品构成与账号关系

| 角色  | 定位               |
| --- | ---------------- |
| 兴聊  | 子平台（1V1 视频 / 语音） |
| 言聊  | 子平台（1V1 视频 / 语音） |
| 星盈通 | 聚合端，统一操作兴聊与言聊账号  |

### 关键规则

1. **账号需先在子端注册**：使用星盈通前，建议先下载并注册好兴聊、言聊账号；如需绑定邀请关系，需先在账号本人名下完成绑定，再登录星盈通。
2. **不支持多端同时登录**：星盈通与兴聊、言聊之间 **不能同时登录**（兴聊与言聊之间亦同）。在一端登录后，另一端会被强制下线。请保持单端登录。
3. **数据基本互通、操作统一**：星盈通可统一操作兴聊与言聊的账号与业务，但底层账号、余额等仍分属各子端。

---

## 三、核心功能概览

- **统一登录管理**：一处登录，管理兴聊、言聊两个账号。
- **通话 / 接单**：在星盈通内接听通话、处理消息匹配（可通过聊天设置开启通话按钮）。
- **收益与提现**：查看收益明细、发起提现。
- **邀请赚钱**：通过二维码 / 下载链接邀请用户，发展自己的团队。
- **认证**：主播认证、女神等级与视频认证。
- **账号安全**：账号注销、异常处理等。

## 四、使用指南

### 4.1 注册与登录

1. 先下载并注册 **兴聊**、**言聊** 账号（如需绑定邀请关系，先在本人账号下完成绑定）。
2. 再下载并登录 **星盈通**，即可统一操作两个子端账号。
3. **同一时间只登录一端**：若「登录兴聊后，星盈通自动退出」，属正常现象，建议保持单端登录；需要在哪个端提现时，再登录该端即可。

### 4.2 开通接单 / 接听通话

- 在星盈通「我的」页面找到通话入口，进入 **通话设置** 页面，开启对应开关即可。
- 也可在 **聊天设置** 中开启「通话按钮」与「消息匹配」。
- 若设置后仍异常，可尝试 **退出重新登录**。

### 4.3 提升流量与推荐度

账号没有推流、匹配少，多与 **推荐度 / 推流机制** 有关，可按以下方法提升：

1. 确保头像清晰真实，及时更新昵称和签名；
2. 首页「**闪电发力**」多点击，冷却时间为 **5 分钟 / 次**，点击越多排名越靠前；
3. 保持 **接通率**，接通率越高排名越靠前；
4. 接听电话尽量保持 **通话时长**，通话越长排名提升越高，通话结束后对方的评价也会影响排名；
5. 及时回复消息，**私信有效回复率偏低会触发停止推流**；
6. 不方便回复时，可先 **关闭匹配按钮**，方便时再开启。

> 提示：系统为 **不定时自动推流**；没有用户时，也可主动找用户聊天，或主动给用户打电话（对方接通即有正常收益）。多发动态、勤换头像、完善主页资料同样有助于提升曝光。

### 4.4 收益规则

- 基本公式：**资费 × 分成 = 收益**，**15 星光值 = 1 元**。
- 具体收益以系统到账为准，系统自动计算后发放。
- 如对方使用 **活动币 / 赠送币**，收益比例会相应减少；使用一张 **视频卡** 时，系统补贴 **15 星光值**。
- 礼物分成比例固定（如 17% 等以系统显示为准），不因个人调整；赠送币多来自充值页面的充值赠送。

### 4.5 提现规则

**提现门槛**

- 星盈通内发起提现，需要 **兴聊、言聊双端各满 100**（「双端 100」）。
- 也可在 **兴聊 / 言聊子端单独提现**（单边满足 100 即可）。

**到账时间（心动值与星光值一致）**

| 提现时间         | 到账时间       |
| ------------ | ---------- |
| 周一           | 周三 24 点之前  |
| 周二           | 周四 24 点之前  |
| 周三           | 周五 24 点之前  |
| 周四           | 下周一 24 点之前 |
| 周五 / 周六 / 周日 | 下周二 24 点之前 |
| 节假日          | 另行通知       |

**其他注意**

- 提现需先 **签署提现协议**；若协议签不了，多为浏览器开启了 **无痕浏览**，关闭后重试即可。
- 若为 **打包提现**（经公会打款），请联系 **公会 / 邀请人**；银行卡显示「已到账」但未收到时，可先向公会核实。
- **封号期间提现会被驳回**，需解封后重新发起提现。

### 4.6 主播认证

- 认证入口：「我的」页面 → **认证**。
- 可进行主播认证、女神等级认证、视频认证等；认证通过后，等级提升，通话资费也会对应提高。
- 「女神等级」页面可查看等级与资费规则（如聊天资费档位）。
- 审核由审核人员自行判断，合格即通过；未通过的可根据拒绝理由修改后重新上传。审核量较大时，可联系客服催促。

### 4.7 账号注销

- 操作路径：「我的」→ **设置** → **账号安全** → **注销账号**。
- 提交注销后进入 **7 天犹豫期**，犹豫期内可取消注销，7 天后自动注销；注销后即可重新注册。
- **注意**：注销星盈通后，绑定的 **兴聊、言聊账号也会一并注销**，且账号余额会清零，请谨慎操作。若尚有余额，建议先提现再注销。

### 4.8 邀请赚钱

- 入口：「我的」页面 → **邀请赚钱**，下滑可查看二维码和下载链接。
- 邀请女用户注册后，可在本人名下绑定被邀请人；被邀请人需先下载兴聊、言聊完成绑定，再下载星盈通。
- 如未显示邀请二维码，可确认当前端是否为兴聊。

## 五、账号异常与违规处理

### 5.1 限流 / 恢复流量

- 出现 **限流、漏接限流、未接限流** 等情况，可联系客服申请，客服确认后会进行恢复（一般 5 分钟左右生效）。
- 频繁限流通常与 **接通率 / 回复率偏低** 有关，恢复后建议按 4.3 的方法维护账号状态。

### 5.2 账号异常 / 封号

- 若提示「账号异常，请与客服联系」，客服会要求提供 **绑定手机号**、**提现姓名** 与 **身份证后 4 位** 进行身份核实。
- 封号原因常见为违反平台规范（如违规内容多次累犯会 **永久封号**）；封号期间 **只能等待到期系统自动解封**，人工无法提前解封。
- 对封禁有异议的，可通过 **邮件申诉**：自行编写申诉原因，发送至指定邮箱（xingliao@xingliao.chat），一般 **7 个工作日内** 答复（结果以相关工作人员审核为准）。
- **永久封号后的余额**：账号被封禁 **15 个工作日** 后，可咨询客服申请余额提现。

### 5.3 视频 / 内容规范要点

- 系统会 24 小时实时监控，一旦发现违反平台用户行为规范的行为，将予以封号处理，情节严重的 **永久封号**。
- 主播出现 **未化妆出镜、灯光昏暗、通话中违规、镜头切晃频繁、故意黑屏、多次秒挂、主动静音、躺播或未露全脸** 等消极视频行为，将 **永久取消 1V1 视频权限**。
- 详细条款以《平台用户行为规范》《平台视频行为规范》《用户协议》为准。

## 六、安全提示

- 请勿在平台外与对方发生任何形式的钱财往来；对方向您提出转账、发红包、借钱等请求时，务必提高警惕。

- 请勿向他人泄露手机号、身份证号等个人信息；平台不会将用户关键信息提供给第三方。

## 八、常见问题速查

| 问题               | 解答                                                   |
| ---------------- | ---------------------------------------------------- |
| 为什么兴聊和星盈通不能同时登录？ | 目前不支持双端登录，两端登录会互相强制下线，建议保持单端登录。                      |
| 打视频没人接怎么办？       | 多发动态、更换头像、完善主页资料，主动找用户聊天；也不定时推流，可主动打电话。              |
| 星盈通怎么开通接单？       | 在「我的」页面打开通话按钮，进入通话设置开启对应开关，或在聊天设置开启通话按钮与消息匹配。        |
| 打视频资费怎么提高？       | 提升等级（女神等级）后，资费会对应提高。                                 |
| 提现多久到账？          | 周一至周日按对应周期到账（详见 4.5 到账时间表），节假日另行通知。                  |
| 为什么提现不了？         | 需兴聊、言聊 **双端各满 100**；或到子端单边提现。签约失败可关闭无痕浏览后重试。         |
| 封号后还能提现吗？        | 封号期间提现会被驳回；永久封禁的账号需满 **15 个工作日** 后咨询客服申请余额提现。        |
| 注销后还能重新注册吗？      | 可以。提交注销后有 **7 天犹豫期**，期满自动注销，注销后即可重新注册。               |
| 注销星盈通会影响其他账号吗？   | 会。注销星盈通后，绑定的兴聊、言聊账号也会同步注销，余额清零。                      |
| 在哪看自己的相册 / 资料？   | 「我的」页面 → **平台资料** → 编辑资料查看；相册审核由审核人员判断，未通过可按理由修改后重传。 |
